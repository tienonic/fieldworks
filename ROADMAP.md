# Roadmap

## 1. Get one station working

Choose the sensors, interfaces, power, enclosure, mounting, and communications path. One build we can actually assemble.

## 2. Prove every reading

Follow each measurement from the sensor to the logger, storage, and final export. Record calibration, missing data, and failure behavior.

## 3. Put it in the field

Install the station and leave it running. Track data quality, weather exposure, connectivity, power, and the maintenance it actually needs.

## 4. Give the data context

Pair readings with irrigation events, field notes, photos, and maintenance records. A number without context is not enough.

## 5. Publish what works

Share the tested design, data format, installation notes, and what broke along the way.
