# Status

FieldWorks is still a prototype. The next real milestone is one complete station running in the field with measurements we can trust.

## What we are doing now

- Locking the first station build
- Testing sensors, power, mounting, and the enclosure as one system
- Connecting measurements to irrigation events and maintenance notes
- Writing down the test process so we can run it again

## What still has to happen

- Finish the sensor and station configuration
- Prove the full signal path on the bench
- Install the station and define what counts as a pass
- Settle the data format for readings, events, and maintenance
- Publish the build and what we learned from it
