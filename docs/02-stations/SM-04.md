## Purpose

Build a fourth soil-profile node from the validated SM-01 hardware and firmware design.

## Station interface

**Inside:** 3 x 200SS tension probes, 1 x 200TS temperature probe, 1 x VA3 adapter, and 1 x ENTS box with solar/battery power.

**Data expected:** `tension_shallow_kpa`, `tension_middle_kpa`, `tension_deep_kpa`, `soil_temp_c`, four raw voltages, and station-health fields, all identified as `SM-04`.

**Question answered:** Does the fourth location confirm meaningful spatial variation across the four soil profiles?

## Connection map

Three 200SS sensors and one 200TS feed the VA3. Four separate 0-3 V VA3 outputs feed four ENTS ADC channels. Firmware maps each channel to a fixed depth and sends tension, temperature, battery, and station ID `SM-04` over US915 LoRaWAN.
