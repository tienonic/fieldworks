## Purpose

## Station interface

**Inside:** 3 x 200SS tension probes, 1 x 200TS temperature probe, 1 x VA3 adapter, and 1 x ENTS box with solar/battery power.

**Data expected:** `tension_shallow_kpa`, `tension_middle_kpa`, `tension_deep_kpa`, `soil_temp_c`, four raw voltages, and station-health fields, all identified as `SM-02`.

**Question answered:** How does the second site's soil profile compare with SM-01?

## Connection map

Three 200SS sensors and one 200TS connect to the VA3. Its four 0-3 V outputs connect to four ENTS ADC channels. The node reports depth-specific tension fields, soil temperature, battery state, and station ID `SM-02` over US915 LoRaWAN.
