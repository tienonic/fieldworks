# SM-02 — Soil Monitoring Station 2

Status: blocked
Owner: unassigned

## Purpose

Second soil-profile node using the validated SM-01 hardware and firmware design.

## Station interface

**Inside:** 3 × 200SS tension probes, 1 × 200TS temperature probe, 1 × VA3 adapter, and 1 × ENTS box with solar/battery power.

**Data expected:** `tension_shallow_kpa`, `tension_middle_kpa`, `tension_deep_kpa`, `soil_temp_c`, four raw voltages, and station-health fields, all identified as `SM-02`.

**Question answered:** How does the second site's soil profile compare with SM-01?

[See the complete data contract and example payload](data-contracts.md#soil-profile-record).

## Connection map

200SS shallow, middle, and deep sensors and the 200TS connect to the VA3. Its four 0–3 V outputs connect to four ENTS ADC channels. The node reports stable depth-specific tension fields, soil temperature, battery state, and station ID `SM-02` over US915 LoRaWAN.
